\section{实验要求}
% ==================================================================

本次实验的任务是借鉴实验 3.2 中基于 Shamir 门限秘密共享的投票统计方案，实现三个人对于他们拥有的数据的平均值的计算。具体而言，我们需要在不直接泄露三人各自原始数据的前提下，通过秘密共享与加法同态协议完成隐私求和，再由结果方恢复总和并计算平均值。

为便于后续实现和分析，我们在开始实验之前进一步明确以下边界条件：

\begin{itemize}
    \item 参与者数量固定为三人，采用 $(2,3)$ 门限方案：共生成 3 份份额，任意 2 份可恢复秘密，少于 2 份无法恢复。
    \item 威胁模型为半诚实模型：各参与方按协议执行，但会尝试根据自己收到的信息推断他人的原始数据。
    \item 不考虑恶意参与方伪造份额、合谋攻击或拒绝服务等主动攻击。
    \item 实验环境使用 Python 3.11，模数取 $p=1000000007$，足以避免秘密值在模运算中发生回绕。
\end{itemize}

% ==================================================================
\section{实验原理}
% ==================================================================

\subsection{Shamir 门限秘密共享}

Shamir $(t,n)$ 门限秘密共享方案的核心思想是：将秘密 $s$ 嵌入一个 $t-1$ 次多项式，然后将该多项式在 $n$ 个不同点上的取值作为 $n$ 份份额分发给 $n$ 个参与方。任意 $t$ 份份额可通过拉格朗日插值重构出原多项式，从而恢复秘密；而任意少于 $t$ 份的份额则无法提供关于 $s$ 的任何信息。

在本实验中，我们使用 $(2,3)$ 门限方案，即 $t=2$，$n=3$。对每个参与方的秘密 $s$，我们构造一个随机一次多项式：

\[
f(x) = s + r \cdot x \pmod{p}
\]

其中 $r$ 为 $[0, p)$ 内的随机系数。然后计算该多项式在 $x=1,2,3$ 处的值 $f(1), f(2), f(3)$，分别作为分给三个计算方的份额。由于多项式次数为 1，任意 2 个点即可唯一确定该多项式，进而在 $x=0$ 处恢复出秘密 $s$。

\subsection{加法同态性质}

Shamir 秘密共享的一个重要性质是加法同态：若多个参与方为各自的秘密各自构造了多项式，那么各计算方将自己收到的份额直接相加后，得到的「局部和份额」恰好是「总和多项式」在相应点上的取值。

具体而言，设三个用户的秘密分别为 $a$、$b$、$c$，各自构造的多项式为：
\[
f_1(x)=a+r_1x,\quad f_2(x)=b+r_2x,\quad f_3(x)=c+r_3x \pmod{p}
\]

第 $i$ 个计算方收到的三份份额分别为 $f_1(i)$、$f_2(i)$、$f_3(i)$，其局部和为：
\[
d_i = f_1(i) + f_2(i) + f_3(i) \pmod{p}
\]

由于多项式加法在相同点上的值等于值的加法，$d_i$ 恰好等于总和多项式 $F(x)=(a+b+c)+(r_1+r_2+r_3)x$ 在 $x=i$ 处的取值。因此，任意两个 $d_i$ 即可通过拉格朗日插值恢复总和 $S=a+b+c$。

\subsection{拉格朗日插值重构}

给定 $t$ 个点 $(x_1, y_1), \dots, (x_t, y_t)$，拉格朗日插值多项式为：
\[
L(x) = \sum_{i=1}^{t} y_i \prod_{j \neq i} \frac{x - x_j}{x_i - x_j} \pmod{p}
\]

在本实验中，我们只需在 $x=0$ 处求值来恢复秘密总和：
\[
S = L(0) = \sum_{i=1}^{t} y_i \prod_{j \neq i} \frac{-x_j}{x_i - x_j} \pmod{p}
\]

其中除法在模 $p$ 下通过费马小定理实现：$\frac{a}{b} \equiv a \cdot b^{p-2} \pmod{p}$。

\subsection{协议整体流程}

综合以上三个组件，本实验的完整协议如下：

\begin{framed}
\begin{enumerate}
    \item \textbf{秘密分发阶段：} 每个用户 $U_k$ 输入私有数据 $s_k$，构造随机一次多项式 $f_k(x)=s_k+r_kx \bmod p$，计算份额 $f_k(1), f_k(2), f_k(3)$，分别发送给三个计算方。
    \item \textbf{局部求和阶段：} 每个计算方 $C_i$ 收到三份份额后，计算局部和 $d_i = \sum_{k=1}^3 f_k(i) \bmod p$。
    \item \textbf{重构阶段：} 结果方任取两个局部和（如 $d_1, d_2$），通过拉格朗日插值恢复总和 $S = a+b+c$。
    \item \textbf{平均值输出：} 计算 $\text{avg} = S / 3$。
\end{enumerate}
\end{framed}

该协议的隐私保护体现在：每个计算方只看到三份随机化的份额，单独一份或两份份额在信息论意义上不泄露原始秘密；同时，最终暴露的总和与平均值是多方聚合后的统计结果，不会追溯到单个参与方的具体输入。

\subsection{核心函数实现}

首先，我们实现了秘密共享所需的基础数学工具。这些函数是整个协议的计算基石。

\begin{lstlisting}[title=function.py：快速幂与多项式操作,frame=trbl,language={Python}]
import random

def quickpower(a, b, p):
    """快速幂计算 a^b % p"""
    a = a % p
    ans = 1
    while b != 0:
        if b & 1:
            ans = (ans * a) % p
        b >>= 1
        a = (a * a) % p
    return ans

def get_polynomial(x0, T, p, fname):
    """构建多项式：x0为常数项系数，T为最高次项次数，p为模数"""
    f = [x0]
    for _ in range(T):
        f.append(random.randrange(0, p))
    f_print = f'f{fname} = {f[0]}'
    for i in range(1, T + 1):
        f_print += f' + {f[i]}x^{i}'
    print(f_print)
    return f

def count_polynomial(f, x, p):
    """计算多项式在x处的值 mod p"""
    ans = f[0]
    for i in range(1, len(f)):
        ans = (ans + f[i] * quickpower(x, i, p)) % p
    return ans
\end{lstlisting}

其中，\texttt{quickpower} 使用二进制快速幂算法，时间复杂度为 $O(\log b)$，是整个模运算体系的基础。\texttt{get\_polynomial} 以秘密值 $s$ 作为常数项、随机生成一次项系数，构造 $(2,3)$ 方案所需的 1 次多项式——这正是 Shamir 方案的核心构造步骤。\texttt{count\_polynomial} 使用霍纳法则的变体计算多项式在指定点处的值。

拉格朗日插值重构的实现如下。该函数接收 $t$ 个点的横坐标与纵坐标，利用费马小定理在模 $p$ 下计算除法逆元，最终在 $x=0$ 处恢复秘密。

\begin{lstlisting}[title=function.py：拉格朗日插值重构,frame=trbl,language={Python}]
def restructure_polynomial(x, fx, t, p):
    """拉格朗日插值重构多项式在x=0处的值，t为使用的点数"""
    ans = 0
    for i in range(t):
        fx[i] = fx[i] % p
        fxi = 1
        for j in range(t):
            if j != i:
                fxi = (-1 * fxi * x[j] * quickpower(x[i] - x[j], p - 2, p)) % p
        fxi = (fxi * fx[i]) % p
        ans = (ans + fxi) % p
    return ans
\end{lstlisting}

该函数按拉格朗日基多项式逐项计算：对于每个点 $(x_i, y_i)$，先计算 $\prod_{j \neq i} \frac{-x_j}{x_i - x_j} \bmod p$，再乘以 $y_i$ 并累加。模逆元通过费马小定理 $b^{p-2} \equiv b^{-1} \pmod{p}$ 高效实现。

以上四个函数构成了本次实验的核心计算层，后续三个文件中的秘密分发、份额聚合与结果重构均建立在这些函数之上。

\subsection{秘密份额生成}

每个用户运行 \texttt{secret.py}，输入自己的 ID 和私有数据。程序会为该数据构造一次多项式 $f(x)=s+rx \bmod p$，计算 $f(1), f(2), f(3)$ 三份份额，并将它们分别写入 \texttt{user\_\{id\}\_\{1,2,3\}.txt} 文件。

\begin{lstlisting}[title=secret.py：用户端秘密份额生成,frame=trbl,language={Python}]
import function as func

p = 1000000007
print(f'模数 p: {p}')

uid = int(input('请输入参与方 id (1/2/3): '))
s = int(input(f'请输入用户{uid}的秘密值 s: '))

shares_x = [1, 2, 3]

print(f'\n用户{uid}的秘密值的多项式及秘密份额：')
f = func.get_polynomial(s, 1, p, str(uid))
for j in range(3):
    share_y = func.count_polynomial(f, shares_x[j], p)
    print(f'  ({shares_x[j]}, {share_y})')
    with open(f'user_{uid}_{j+1}.txt', 'w') as fout:

\subsection{总和重构与平均值计算}

最后，结果方运行 \texttt{avg.py}，任选两个局部和文件（我们以 $d_2, d_3$ 为例），通过拉格朗日插值重构总和 $S$，再除以 3 得到平均值。

\begin{lstlisting}[title=avg.py：总和重构与平均值输出,frame=trbl,language={Python}]
import function as func

p = 1000000007

x_used = [2, 3]
d_values = []
for i in x_used:
    with open(f'd_{i}.txt', 'r') as f:
        d_values.append(int(f.read()))

S = func.restructure_polynomial(x_used, d_values, 2, p)
print(f'重构总和 S = a + b + c = {S}')

avg_direct = S / 3.0
print(f'平均值（直接除法）: {avg_direct}')

inv3 = func.quickpower(3, p - 2, p)
avg_mod = (S * inv3) % p
print(f'3 在模{p}下的逆元: {inv3}')
print(f'平均值（模逆元运算）: {avg_mod}')
\end{lstlisting}

这里我们同时输出了两种平均值计算方式的结果：一是重构后在实数域直接除以 3，二是在有限域中用模逆元 $3^{-1} \bmod p$ 完成等价的除法运算。

\subsection{自动化测试验证}

为了系统性地验证实现的正确性，我们编写了自动化测试脚本 \texttt{test\_lab3.py}，覆盖以下六个测试场景：

\begin{enumerate}
    \item \textbf{基础正确性测试：} 输入 $(3, 6, 9)$，期望总和 $S=18$，平均值 $6.0$。
    \item \textbf{门限一致性测试：} 输入 $(100, 200, 300)$，分别用 $(d_1,d_2)$、$(d_1,d_3)$、$(d_2,d_3)$ 三组组合重构，验证结果均为 $S=600$。
    \item \textbf{非整除测试：} 输入 $(1, 2, 2)$，总和 $S=5$，平均值约为 $1.667$。
    \item \textbf{随机性测试：} 同一输入 $(42, 17, 99)$ 运行两次，验证份额不同但重构总和均为 $158$。
    \item \textbf{隐私性测试：} 验证单个份额值不等于原始秘密值，直观体现份额的随机化效果。
    \item \textbf{较大值测试：} 输入 $(10^6, 2\times 10^6, 3\times 10^6)$，验证总和与平均值在大值场景下仍正确。
\end{enumerate}

测试脚本的核心结构如下：\texttt{run\_full\_flow} 函数接收三个秘密值，自动完成多项式生成、份额分发、局部求和与拉格朗日重构，返回总和与平均值；随后六个测试函数各司其职，通过断言验证结果是否符合预期。

\begin{lstlisting}[title=test\_lab3.py：核心测试框架（节选）,frame=trbl,language={Python}]
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..', 'src'))
import function as func

P = 1000000007
SHARES_X = [1, 2, 3]

def run_full_flow(secrets):
    """运行完整流程：份额生成 -> 局部求和 -> 重构平均"""
    n = len(secrets)
    all_shares = {}
    # 阶段1: 每个用户生成多项式并计算份额
    for uid, s in enumerate(secrets, start=1):
        f = func.get_polynomial(s, 1, P, str(uid))
        for j, x in enumerate(SHARES_X, start=1):
            all_shares[(uid, j)] = func.count_polynomial(f, x, P)
    # 阶段2: 每个计算方求局部和
    d = {}
    for receiver in range(1, n + 1):
        total = 0
        for sender in range(1, n + 1):
            total = (total + all_shares[(sender, receiver)]) % P
        d[receiver] = total
    # 阶段3: 拉格朗日插值重构
    S12 = func.restructure_polynomial([1, 2], [d[1], d[2]], 2, P)
    S13 = func.restructure_polynomial([1, 3], [d[1], d[3]], 2, P)
    S23 = func.restructure_polynomial([2, 3], [d[2], d[3]], 2, P)
    avg_direct = S12 / 3.0
    return {'all_shares': all_shares, 'd': d,
            'S12': S12, 'S13': S13, 'S23': S23, 'avg_direct': avg_direct}

def test_basic_correctness():
    """基础正确性：(3,6,9) -> S=18, avg=6.0"""
    result = run_full_flow([3, 6, 9])
    assert result['S12'] == 18
    assert abs(result['avg_direct'] - 6.0) < 1e-9

def test_threshold_consistency():
    """门限一致性：任意2份恢复结果相同"""
    result = run_full_flow([100, 200, 300])
    assert result['S12'] == result['S13'] == result['S23'] == 600

def test_non_divisible():
    """非整除：(1,2,2) -> S=5, avg=1.667"""
    result = run_full_flow([1, 2, 2])
    assert result['S12'] == 5
    assert abs(result['avg_direct'] - 5 / 3.0) < 1e-9

def test_randomness():
    """随机性：同一输入两次运行份额不同，但重构结果相同"""
    r1 = run_full_flow([42, 17, 99])
    r2 = run_full_flow([42, 17, 99])
    assert r1['S12'] == r2['S12'] == 158
    # 验证份额确实不同
    shares_differ = any(r1['all_shares'][k] != r2['all_shares'][k]
                        for k in r1['all_shares'])
    assert shares_differ

def test_privacy_intuition():
    """隐私性：份额 != 秘密值"""
    result = run_full_flow([12345, 67890, 11111])
    assert result['all_shares'][(1, 1)] != 12345

def test_large_values():
    """大值：(1e6,2e6,3e6) -> S=6e6, avg=2e6"""
    result = run_full_flow([1000000, 2000000, 3000000])
    assert result['S12'] == 6000000
\end{lstlisting}

其中，\texttt{run\_full\_flow} 是测试的核心引擎：它将三次手动运行 \texttt{secret.py}、三次 \texttt{count.py} 和一次 \texttt{avg.py} 的过程整合为一次函数调用，直接在内存中完成全流程模拟。六个测试函数分别从正确性、门限一致性、边界处理、随机隐私和大数据五个维度对实现进行验证，每个函数末尾的 \texttt{assert} 断言确保结果严格匹配预期。
